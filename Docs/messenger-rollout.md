## Плейтест

Все проверки выполняются в игре человеком на ветке `pda-messenger`.

1. **Автоустановка**: зайти за пассажира — в КПК на вкладке программ присутствует «Мессенджер».
2. **Исключения**: проверить КПК ЦК, синдиката (нук-опс), ERT/CBRN, посетителя, волшебника и хамелеона — мессенджера нет.
3. **Каталог**: открыть мессенджер — список контактов из манифеста станции; у непрочитанных чатов красная точка.
4. **Переписка двух игроков**: два игрока на станции — отправка, приём, история в обоих КПК, отображение времени.
5. **Отказ сервера**: обесточить/разобрать TelecomServer — новая отправка даёт «Сервер недоступен»; вернуть питание — сервер снова найден (без перезахода).
6. **Уведомления**: входящее сообщение при закрытом окне КПК — звук `malinov_messenger_notification` и всплывающее уведомление; при открытом окне КПК в чате с отправителем — без уведомления.
7. **Rate-limit**: отправить 5+ сообщений подряд — срабатывает антиспам, таймер обратного отсчёта; проверять на двух игроках (лимит на отправителя).
8. **Mute**: `messengermute <имя>` от админа — заигнорить отправителя (ошибка + баннер «ВЫ ЗАГЛУШЕНЫ ЦК»); `messengerunmute <имя>` — разморозка.
9. **Админ-логи**: просмотреть логи типа `MalinovMessengerSend` / `DeliveryFail` / `RateLimited` / `Mute` после прогона пунктов 4–8.

## Summary изменений для PR

- **Механизм**: картридж КПК «Мессенджер Малинова»; каталог контактов из манифеста станции; переписка через сервер-ретранслятор на базе vanilla `TelecomServer` (частотный канал `MalinovMessengerFrequency`, радиус 500); история до 50 сообщений на контакт; уведомления со звуком; антиспам (окно/лимит CVar'ами); глушение через админ-команды `messengermute`/`messengerunmute`; админ-логи `LogType` 1200–1203.
- **Автоустановка**: `MalinovMessengerInstallerSystem` ставит программу на все PDA станции, кроме исключённых (CentCom/админка, синдикат/пираты/ниндзя, ERT/CBRN, посетители, волшебник/хамелеон, Cluwne/Scurret).
- **Настройка**: CVar'ы `malinov.messenger.{max-message-length, peer-ttl-seconds, history_per_contact, sound_enabled, rate_window_sec, rate_max_msgs}`.
- **Изоляция форка**: всё новое — в `_MalinovStation`; вне форк-папки изменены только минимальные помеченные исключения `Malinov edit`: `LogType.cs` (этап 7), `PdaMenu.xaml` (увеличение окна КПК), `telecomms.yml` (релей мессенджера на TelecomServer).
- **Тесты**: `MalinovMessengerTest` (автоустановка + исключения через рефлексию списка, P2P, релей, история, уведомления, антиспам, глушение, перенос аккаунта между КПК) и `MalinovMessengerAdminLogTest`.
- **Локализация**: en-US + ru-RU, полный набор ключей UI.

## Известные упрощения / долги

1. **Сопоставление контактов по имени** (known simplification): ключ — строка имени из записей станции, а не стабильный уникальный id. Два одинаковых имени разрешаются по тому, кто онлайн на момент отправки. Оставлено осознанно; при необходимости мигрировать на account-id.
2. **Дифф-исключения не в `_MalinovStation`** — три помеченных `Malinov edit` факта (см. Summary), каждый минимален и документирован.
